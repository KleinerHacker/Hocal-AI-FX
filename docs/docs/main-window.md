# Main window

The main window opens when the application starts.

## Menu

| Menu | Entry | Shortcut     | Action                |
|------|-------|--------------|-----------------------|
| File | Exit  | `Ctrl` + `Q` | Closes the main window |

On macOS the shortcut is `Cmd` + `Q`.

## Flow list

The list on the left shows the flows you can choose from. It currently holds three example flows:

* Text to Image
* Image to Image
* Upscale

When no flow is available, the list says so.

## Content area

The area to the right of the list shows which flow is selected. While nothing is selected, it asks
you to pick a flow on the left.
