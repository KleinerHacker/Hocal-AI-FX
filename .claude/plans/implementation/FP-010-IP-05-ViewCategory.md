# FP-010-IP-05: Kategorie Ansicht

## Voraussetzungen

* IP-03, IP-10, IP-11

## Aufgabe 1: Vorbereitung

* [ ] Skills `component`, `ui-styling`, `translation` und `testing` laden

## Aufgabe 2: Seite

* [ ] Sprachliste aus der Registry, „Systemvorgabe“ zuerst, Einträge mit eigenem Namen
* [ ] Nur vollständige Sprachen anzeigen, Liste scrollbar
* [ ] Erscheinungsbild: Systemvorgabe, hell, dunkel; wirkt sofort in allen offenen Fenstern
* [ ] Sprachwechsel wirkt nach Neustart, Hinweis am Feld

## Aufgabe 3: Tests

* [ ] Tests der Auswahllogik und der Seite
* [ ] Neue Sprache erscheint ohne Änderung der Seite

## Abschluss

* [ ] Gradle `build` über einen Agenten mit vollem Pfad ausführen
* [ ] Skill `project-docs`: README, MkDocs, KDoc prüfen, CHANGELOG nur bei sichtbarer Änderung
* [ ] Plan-Datei mit `git rm` entfernen, Feature-Plan und Feature-Status im selben Änderungssatz abhaken
